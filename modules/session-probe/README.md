# Session platform probe

Disposable independent `SessionOutputProvider` example for actual M20, Node and
local-relay acceptance. It uses only the public SDK, does not start a shell and
requires the platform-established isolated process profile. Exact target,
package/UI/native review and separate service/human rights remain mandatory.

Build with `python modules/session-probe/build_probe_package.py --output PATH`.
The builder validates; it does not install, approve, enable or publish anything.
The local UI is a verification tool, not a host-maintenance application.
